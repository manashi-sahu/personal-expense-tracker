# Personal Expense Tracker

A simple Python-based Personal Expense Tracker built using Core Python.

This project allows users to add and manage expenses, view expenses by category, calculate category-wise totals, check their budget, and view an overall expense summary.

## Features

* Add new expenses
* View all expenses
* View expenses by category
* Calculate total expenses for a category
* View overall expense summary
* Check whether expenses are within a given budget
* Menu-driven program
* Basic input validation for expense amounts and budgets

## Concepts Used

This project was built using Core Python concepts:

* Variables
* Lists
* Dictionaries
* Conditional statements
* `for` loops
* `while` loops
* Functions
* Function parameters
* `return`
* `try` and `except`
* `break`
* String methods
* Built-in functions such as `sum()`, `max()`, `min()`, and `len()`
